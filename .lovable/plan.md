# Hide the "Edit with Lovable" badge

The badge is currently shown on the published site (gadgetopediabd.lovable.app / gadgetopedia.shop). Your workspace is on a Pro plan, which is required to hide it.

## Change

1. Update the publish setting to hide the badge on all published deployments (one toggle — no code changes, no republish of the site needed).
2. Confirm the setting reads back as hidden.

## Result

The "Edit with Lovable" badge will no longer appear on your live site. If you ever want it back, it can be re-enabled at any time.
